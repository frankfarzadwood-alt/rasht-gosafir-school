# Safir visual presentation

This presentation update uses the supplied GO SAFIR logo, a white default canvas, real book-cover thumbnails, English book/series names and playful catalogue/game cards. The optional saved dark-mode preference remains available.

The Persian content picker reads انتخاب محتوا and the welcome form reads نام شما. The existing nickname storage field is retained for compatibility. IELTS welcome-menu availability now reflects the actual released question pool.

Canonical book/school data, question IDs, release order, mappings, scoring, media bytes and personal-work/progress storage identities are unchanged. Cover images are catalogue illustrations only and never exercise clues or page-screenshot gameplay.

## Catalogue artwork

The logo is an unchanged copy of the user-supplied لوگو سفیر.png. Collection photos are unchanged copies of the three user-supplied Pictures images. Individual Project, Oxford and IELTS thumbnails are first-page covers rendered from the supplied PDFs. Evolve thumbnails show the original first-edition workbook covers.
