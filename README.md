# Rasht Gosafir School

English Quest: Persian-first English practice with the completed school section and all eighteen requested books in one cumulative app.

The collection includes Evolve 1-6 workbook/test/audio practice, Project 1-5 workbooks/audio, all three Oxford Word Skills levels, IELTS Grammar 6.5+, IELTS Vocabulary 6.5+, IELTS Vocabulary up to 6.0 and Speaking Maximizer. The shared bank contains 31,000 questions including school, with separate unscored writing and speaking practice.

Games use native controls, independently generated art, original text and code-native diagrams. Evolve/Oxford recommendations retain the supplied mappings, including exact Oxford sections. Speaking Maximizer also includes forty-four user-supplied bonus recordings, explicitly separate from its book topics.

See [the cumulative handover](LOVABLE_IMPORT.md) and the book-specific coverage documents in docs. The school section and earlier canonical payloads/progress rules are retained. The single cumulative ZIP contains this complete source project and its local runtime media.
